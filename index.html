About PHOTO COFFEE

Coffee Identification System based on Computer Vision.

System Overview

PHOTO COFFEE is a coffee identification system developed to classify green coffee beans into four varieties: Arabika, Robusta, Excelsa, and Liberika.

The system utilizes digital image processing, computer vision, and deep learning through the YOLOv8n-seg architecture.

Model Information

Model Architecture: YOLOv8n-seg
Task: Object Detection and Instance Segmentation
Input: Coffee Bean Images
Output: Coffee Class, Confidence Score, and Segmentation Mask

Supported Coffee Varieties

The model supports four coffee bean categories.

Arabika Ekselsa Liberika Robusta

System Purpose

To support coffee identification through image-based analysis and provide visual information about detected coffee beans.
